# 🏨 App Hotel

Projeto acadêmico desenvolvido em .NET MAUI para a disciplina de Desenvolvimento de Sistemas.

## ✨ Funcionalidades

- Cadastro de reservas
- Seleção de tipo de quarto
- Controle de adultos e crianças
- Validação de datas
- Cálculo automático da reserva
- Tela de informações do projeto

## 🎨 Interface

O projeto foi desenvolvido com uma identidade visual em tons de:
- bege claro
- marrom
- nude rosado

Buscando transmitir uma aparência moderna, elegante e aconchegante.

## 🛠️ Tecnologias Utilizadas

- .NET MAUI
- C#
- XAML
- Visual Studio 2026
- GitHub
